# PureDrive Myjnia Ręczna

Strona myjni ręcznej PureDrive w garażu Galerii Wileńskiej (Warszawa, ul. Targowa 72). Statyczny HTML, CSS i JavaScript, bez budowania.

- `index.html`: cała strona
- `web/`: zdjęcia i wideo

Zdjęcia i rolki pochodzą z puredrive.pl, Instagrama @puredrive_myjnia i wizytówki Google. Zdjęcie wnętrza przed/po jest demonstracyjne (Pexels).
